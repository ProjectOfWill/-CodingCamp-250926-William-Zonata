# Finance Tracker — Quick Start

## How to Use
1. Open `index.html` in your browser (no server needed)
2. Add transactions using the form
3. Watch the balance, chart, and summary update automatically

## Features
- ✅ Add/delete transactions with validation
- ✅ Track income and expenses
- ✅ Visual pie chart by category
- ✅ Monthly summary with navigation
- ✅ Sort transactions (date, amount, category)
- ✅ Custom categories
- ✅ Spending limit alerts
- ✅ Dark/light mode toggle

## Troubleshooting

### Chart or Summary Not Updating?
If you experience issues:
1. Make sure you're using a modern browser (Chrome, Firefox, Edge, Safari)
2. Check the browser console for errors (F12)
3. Clear localStorage: Open DevTools → Application → Local Storage → Right-click → Clear
4. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

### Chart.js CDN
The app loads Chart.js from jsdelivr CDN. If you're offline, the chart won't display.

## Data Storage
All data is stored locally in your browser using localStorage. No data leaves your computer.
